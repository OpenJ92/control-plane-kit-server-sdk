Private one-shot numeric-loopback HTTP client. The installed unchanged ASCII origin-form path is validated before connect; only the independently bound container port is used. No DNS-selected host, proxy, credential/forwarded-header delivery, redirect, auth retry, pooling or repeat exists. One absolute monotonic deadline covers connect/send/status/headers/body; every receive updates the remaining socket timeout, including line parsing, so trickles cannot reset it. The socket closes in finally. Status/headers use bounded CRLF lines,32KiB/64-field headers and closed framing. Conflicting/duplicate lengths or transfer coding, invalid headers and incomplete bodies yield unavailable evidence without service status. Supports Content-Length, close-delimited and chunked bodies; chunk extensions and interim1xx are conservatively unsupported. Normal evidence requires complete framing. A real cap+1 byte is the explicit overflow exception; no response content escapes, capped MALFORMED cannot pass. No body-hash claim exists in this first profile.
