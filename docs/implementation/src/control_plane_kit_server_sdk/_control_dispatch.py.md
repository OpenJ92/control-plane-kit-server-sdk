This private verification-extra owner captures one installation's receiving context. Pure configuration validation runs before host collision checks and again at preparation before any descriptor call. Preparation snapshots each descriptor once, builds one outcome codec per registered variable, records sorted installed names and allocates replay only when variables are declared. Frozen fields hide all context from repr; the contained registry is trusted conventional state, not deep immutability or a sandbox. Two preparations have separate registry/replay objects.

The moved static interpreter admits the dedicated grant, binds installed target/declaration and emits Core receiver V3 capabilities/status bytes. Static status is registry coverage. The moved variable interpreter admits the actual operation/variable/candidate, binds target before registry lookup, produces canonical receiver V2 READ/APPLY result envelopes and delegates unchanged replay behavior to its existing owner. No new verifier, callback protocol, HTTP parser, threadpool, framework import or durable state exists here. Health is the existing neutral dispatcher captured by identity, not reimplemented.
