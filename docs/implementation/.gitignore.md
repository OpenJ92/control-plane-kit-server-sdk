Six patterns keep ordinary Python bytecode, virtual environments, build/dist
directories and egg-info output out of default Git discovery. They do not
untrack existing files, prevent force-add, or filter Docker build context.
The [Docker context rules](.dockerignore.md) have a separate owner.

[Repository-policy tests](tests/test_repository_policy.py.md) require these
patterns as a subset, so additional patterns are permitted by that assertion.
This is repository hygiene, not a credential scanner or access-control rule.
