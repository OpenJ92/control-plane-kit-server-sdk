Nine owning tests use standard HTTP servers on ephemeral loopback ports inside the ordinary Docker suite. Generated signed health/static/command fixtures exercise the public installer and actual request parser. Coverage includes passive single publication and failures, exact outcomes/correlation/static authority, legacy/mixed replay, raw protocol/alias/Expect/header/body denials, unchanged ordinary body/header/keepalive/legacy behavior, copied-handler rejection, two legitimate server contexts, premature APPLY EOF, disconnect without retry and product-owned bind/shutdown/close.

The application records only method/path/body, never credentials; protected denials assert zero application calls/logs and callbacks. A representative non-ASCII request separator verifies reservation matches the host lexer. HTTP/0.9, nested escape exhaustion and raw-reserved traversal have focused witnesses, not an RFC matrix. Helpers open no host-published port or extra process; every socket uses a context/finally close. The test host sets non-daemon request workers and joins them on server_close, releases bounded callbacks before joining, and invokes shutdown outside the serving thread. This proves adapter ownership for those schedules, not arbitrary callback cancellation or product/native/live acceptance.
